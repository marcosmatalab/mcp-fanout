# Session context (bait)

These files stand in for what an agent had in view during a session: a few config and note
files carrying UNIQUE planted tokens. They are bait in our OWN house, not markers injected into
a third party (see docs/DOCTRINE.md): a planted token is our data, in our file, and we only
learn something if a server's own egress carries it back out.

Each token below is unique and greppable, so if it appears in an outbound payload the match is
unambiguous. The tokens are synthetic and belong to nobody.

Do not put a real secret here. The point is measurement, not exposure.
